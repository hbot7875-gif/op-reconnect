🧩 MOBILE SETUP
Web Scrobbler on your phone

Most phone browsers can't run extensions at all — Chrome and Safari on mobile don't support them. Firefox for Android does, and Web Scrobbler runs on it the same way it does on desktop.

Why this matters: Web Scrobbler only sees what plays inside the browser tab. Music played through the native Spotify app is invisible to it — you have to actually open Spotify's web player inside Firefox itself for any of this to count.
1
Install Firefox for Android

From the Play Store, if you don't already have it. Any other mobile browser won't work for this.

Get Firefox ↗
2
Add the Web Scrobbler extension

In Firefox, tap the ⋮ menu → Add-ons (sometimes labeled "Extensions"). Search for "Web Scrobbler" and tap Add to Firefox. If search comes up empty, open the link below directly.

Web Scrobbler on AMO ↗
3
Open the extension's settings

Tap the Web Scrobbler icon (in Firefox's menu or the toolbar), then find its Settings/Options screen, and open the Accounts tab.

4
Enable Webhook and paste your URL

5
Play music inside Firefox itself

Open open.spotify.com (or another supported web player) as a tab in Firefox for Android and play from there — not the Spotify app. Web Scrobbler picks it up automatically from then on.

Not seeing streams come through? Go to Settings → Stream check in the main game — it shows exactly what the network just heard from you in the last 24 hours.
