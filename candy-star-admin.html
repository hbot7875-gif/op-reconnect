⑤ Validate a playlist

Only works for playlists the connected account can actually read via Spotify's API — in practice, its own. Reading another agent's playlist gets a 403 from Spotify even when it's public, because this app is still in Spotify's Development Mode. Use the bookmarklet below for those instead: it reads the tracklist right in your browser (a real page view has none of that restriction) and sends it here to check the same rules.

For playlists from other accounts

Desktop: drag the button below to your bookmarks bar. Mobile Chrome (no bookmarks bar to drag to): tap "Copy code", bookmark any page, open Chrome's bookmark manager, edit that bookmark and paste the copied code over its URL, save it, then open it later by typing its name in the address bar while on the playlist page. Either way: open the playlist on open.spotify.com (log in first if it's not public to you) and run it — it'll scroll, collect the tracklist, and show the same pass/fail report right there on Spotify's page.
