CANDY STAR — ADMIN

🍬 Catalog & Spotify control

Site-owner tools for the Candy Star Generator: refresh the BTS catalog, manage the filler library, connect the one site-wide Spotify account, and trigger a real generation for validation. Not part of the player-facing game — reach it only from this direct link.

Spotify connection

One site-wide account, not per-agent. Only ever connect the account this game should generate real playlists from.

Checking…

BTS song catalog

Pulls fresh from iTunes Search (free, no auth) and overwrites bts_song_catalog. Empty until this has run at least once — that's expected on a brand-new project, not a bug.

Filler library

The non-BTS "not just BTS on repeat" tracks the generator weaves in. Import a whole playlist (K-pop tracks are filtered out automatically) or add one track at a time.

Generate a playlist (validation)

Runs the real generator against the connected Spotify account — same rule engine agents' Candy Star screen uses. One line per focus song: key,multiplier — get a song's key from "Check catalog size" output or the live function's getBTSCatalog response.
