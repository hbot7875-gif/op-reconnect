How it works

Playlists you add sit at the top of that district's Vault, above the automatically matched ones. Agents just see the list — nothing tells them how a playlist was made, so add the one you would want them to use. The title comes from Spotify itself, so it always matches what agents open. The same playlist can only be in the Vault once.
